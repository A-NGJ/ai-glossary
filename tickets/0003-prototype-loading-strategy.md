## Question

Which loading strategy *feels* right in practice: a small always-loaded
glossary (CLAUDE.md-style) or an indexed on-demand lookup? Build the cheapest
concrete artifacts that let the operator react: e.g. a realistic ~50-term
glossary file wired into a session both ways, then observe whether the agent
(a) uses the terms unprompted when always-loaded and (b) actually consults the
index when on-demand. Links the prototypes as assets. HITL — the operator
judges the feel; informed by the context-loading research findings.
