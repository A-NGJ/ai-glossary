# Personal glossary lookup

Read the file `../glossary.md` (one directory above this project's root) with the
Read tool. It is a flat bullet list: `- **term** — meaning`, optionally followed by
*(not: …)* anti-terms to avoid and *(aka: …)* aliases.

Use the canonical terms in everything you write; never use a word listed under
`not:`. Inside a repo, that repo's CONTEXT.md wins over this glossary on conflict.
